# Exodus artwork

The glass renders, favicon, and seated-wedge brand geometry are reused from
Farouk's Exodus reference project (`exodus/exodus-app/web`). The silver shell
represents principal; the blue wedge represents yield. Render layers share a
1536 × 1024 canvas, with a 206 px / −28 px wedge displacement.

Public Sans is the self-hosted UI font, sourced from the official Google Fonts
repository (`ofl/publicsans`). Inter and Geist Mono from the reference remain
available as brand/reference assets. Font license files are included in `fonts/`.
